Pizza Time - учебный веб-проект пиццерии с удобным меню и корзиной для оформления заказа.  

✨ Возможности  
🍕 Просмотр меню пиццы  
🥤 Разделы с напитками, соусами и комбо  
🛒 Добавление товаров в корзину  
📦 Формирование заказа  
📱 Адаптивный дизайн для разных устройств  
✅ Валидация данных при оформлении заказа
